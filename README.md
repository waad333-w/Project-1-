# Find It! 🔎🐱

## About

Find It! is a browser-based object-finding game where players help Zozi find the object she is looking for before the 10-second timer runs out.

I chose this game because I wanted to create something simple, interactive, and fun while practicing my HTML, CSS, and JavaScript skills.

## How to Play

1. Click **Start Game!**
2. Read the object Zozi wants.
3. Find and click the correct object.
4. Find it before the 10-second timer runs out.
5. Click **Play Again!** to start a new round.

## Game Conditions

* **Win:** Find the correct object before time runs out.
* **Lose:** The timer reaches zero before the correct object is found.
